# AgroMarket — лабораторная работа

Демонстрационный интернет-магазин фермерских продуктов на React + TypeScript + Vite. Интерфейс на русском языке. Проект подготовлен как самостоятельная учебная реализация по мотивам указанного образца; исходный репозиторий не был доступен для проверки, поэтому точное совпадение с ним не гарантируется.

## Возможности
- адаптивная витрина с категориями и карточками продуктов;
- поиск по названию и фильтрация по категориям;
- добавление товаров в корзину, изменение количества и удаление;
- избранное;
- сортировка по цене и рейтингу;
- оформление демонстрационного заказа с проверкой обязательных полей;
- сохранение корзины и избранного в `localStorage`;
- адаптивная вёрстка для мобильных устройств.

## Запуск
Требуется Node.js 18+.

```bash
npm install
npm run dev
```

Для проверки production-сборки:

```bash
npm run build
npm run preview
```

## Структура
```text
src/
  components/       переиспользуемые компоненты
  data/products.ts  демонстрационные товары
  App.tsx           состояние и логика магазина
  main.tsx          точка входа
  styles.css        адаптивные стили
```

## Примечание
Это frontend-прототип: платежи, реальная авторизация, доставка и серверная база данных не подключены. Изображения загружаются с Unsplash и требуют интернет-соединения.
